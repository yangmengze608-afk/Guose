# Code of conduct

PRIVATE_REPORTING_CHANNEL = CONFIGURED。私密行为/社区事件报告可发送到 `yangmengze608@gmail.com`。

Be respectful, constructive and evidence-led. Welcome newcomers, give actionable
feedback and critique code or claims without attacking people. Harassment,
discrimination, threats, doxxing, unwanted sexual attention and knowingly posting
private information are not acceptable in project discussions or contributions.

Maintainers may remove harmful content, warn participants or restrict participation
proportionately; they should explain decisions while protecting private reports.
Apply these rules consistently, including to maintainers. Disagreement in technical
reviews is welcome when respectful and supported by evidence.

Private conduct or moderation reports may be sent to **yangmengze608@gmail.com**. GitHub vulnerability reporting is for security and does not replace conduct reporting. Never post sensitive incidents publicly.
This project-specific policy is original text, not a claim of certification.
